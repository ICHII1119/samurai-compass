01

プロジェクト概要

武士道の知恵（五輪書・武士道）を基盤とした Pentagon Compass を通じて、参加者が自分の軸（Spirit）を発見し、21日間稽古で鍛え続けるためのプログラム＆PWAアプリ。
技術スタック
🌐
フロントエンド
バニラ HTML / CSS / JavaScript（フレームワークなし）
🔥
Firebase
Firestore（DB）/ Cloud Functions（サーバー処理）
💬
LINE Messaging API
参加者への通知・Webhook受信
📧
EmailJS
診断レポートHTMLメール送信
🚀
GitHub Pages
静的ホスティング・PWA配信
🤖
OpenAI API
道場AIコメント・武蔵BOT生成
